💡 How to get Channel ID:
• Add your bot as admin to the channel.
• Send any message to the channel.
• Visit: https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates
• Find "chat" → "id" (negative number for channels).
• Or use @username (e.g., @mynews).
If messages fail to send, keep this checkbox ON. It routes requests through a free proxy that bypasses browser restrictions.
⚠️ Important:
• The bot must be an admin of the channel to send messages.
• For private channels, use the numeric ID (starts with -100).
• For public channels, you can use @username.
• Messages support HTML formatting.
• The free proxy may have rate limits – for heavy usage, deploy your own proxy.
